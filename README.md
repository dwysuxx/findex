## M4 — Eager vs Lazy comparison

| Version           | Documents | Peak memory | Elapsed |
|-------------------|-----------|-------------|---------|
| eager (lists)     | 124       | 36.60 МБ    | 1.04с   |
| lazy (generators) | 124       | 2.07 МБ     | 1.16с   |

## Lazy (generators): 
документи читаються по одному, і для кожного відразу вважаються токени, які відразу враховуються в Counter. 
Після цього документ та його токени більше не потрібні, і Python звільняє під них пам'ять. 
У будь-який момент у пам'яті знаходиться приблизно один документ плюс Counter, що росте — незалежно від того, скільки всього документів у корпусі.

## Eager (lists)
спочатку всі документи збираються до списку docs,
потім всі вони токенізуються до списку списків all_tokens, потім створюється ще одна, плоска копія all_tokens_flat, і тільки після цього вважається Counter.
У результаті на піку одночасно існують одразу кілька копій всього корпусу в різних формах (документи, списки токенів, плоский список токенів) — 
звідси і в 17 разів більше використаної пам'яті порівняно з lazy-версією
